# Граф мозга дрозофилы по данным FlyWire

Лабораторная работа 2: построение взвешенного ориентированного графа со знаками по полному коннектому мозга *Drosophila melanogaster* (FlyWire, FAFB v783) и проверка данных на согласованность.

| --- | --- |
| Исполнитель | Вигалок Валерия Вениаминовна |
| Группа | Прог-С3-26, Университет «Дубна» |
| Язык | C++17 |

**Главные результаты.** Граф содержит 138 584 связанных нейрона, 3 732 460 направленных связей и 50,7 млн синапсов. 57,5% связей возбуждающие, 34,1% тормозящие. Медиатор в таблице связей полностью совпадает с медиатором нейрона-отправителя, поэтому знак связи можно приписывать нейрону целиком.

## 1. Цель и задачи

Цель — собрать из открытых данных FlyWire граф «нейрон → нейрон» со знаками связей и проверить корректность исходных данных, в первую очередь применимость правила «один нейрон — один медиатор».

1. Загрузить таблицу связей и сложить строки одной пары нейронов в одно ребро.
2. Проверить инварианты: ни один синапс не должен потеряться при группировке.
3. Определить знак каждой связи по медиатору отправителя и проверить согласованность медиаторов в разных таблицах.
